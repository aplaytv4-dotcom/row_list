# Attendance System

Программа для **учёта присутствия сотрудников и формирования отчётов**.
Позволяет быстро отмечать присутствие/отсутствие сотрудников и автоматически формировать **ежедневные и периодические отчёты в Word**.

---

## Основные возможности

* Учёт присутствия сотрудников
* Выбор причины отсутствия
* Обязательный комментарий для причины **"Отпросился"**
* Автоматическое формирование отчётов:

  * ежедневный отчёт
  * отчёт за месяц
  * отчёт за квартал
  * отчёт за год
* Поддержка **вакантных должностей**
* Склонение слов в отчётах
  *(1 человек, 2 человека, 5 человек)*
* Формирование документов **DOCX**
* Работа с базой данных **SQLite**

## Формат файла сотрудников

Файл `employees.txt`

```
Подразделение;Должность;Звание;ФИО
```

Пример:

```
Штаб;Инженер;капитан;Иванов И.И
Штаб;Инженер;капитан;Петров П.П
Штаб;Инженер;капитан;Сидоров С.С
Штаб;Инженер;капитан;ВАКАНТ 19
```

## Генерация отчетов

Программа автоматически формирует отчёты в формате **Word (.docx)**:

### Ежедневный отчёт

Содержит:

* количество сотрудников
* количество присутствующих
* количество отсутствующих
* причины отсутствия
* список сотрудников, которые отпрашивались

### Отчёт за период

Формируется:

* за месяц
* за квартал
* за год

В отчёте выводится:

* статистика отсутствий
* расшифровка причин
* список отпрашивавшихся сотрудников с датами
